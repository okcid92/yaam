# Contexte UI — Next.js

> Généré par Yaam — charte graphique pour projets Next.js.

## Stack UI

- **Framework CSS** : Tailwind CSS
- **Composants** : shadcn/ui
- **Icônes** : Lucide React
- **Polices** : next/font (Google Fonts)

## Composants shadcn/ui disponibles

- Button, Input, Select, Dialog, Toast
- Card, Table, Badge
- DropdownMenu, Popover, Tooltip

## Convention Tailwind

- Classes utilitaires, pas de CSS custom.
- `cn()` de `clsx` + `tailwind-merge` pour les classes conditionnelles.
- Couleurs via `tailwind.config.ts`.
