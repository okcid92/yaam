# Contexte UI — React Native

> Généré par Yaam — charte graphique pour projets React Native.

## Palette

- Couleurs natives iOS/Android respectées.
- Mode sombre supporté via `useColorScheme()`.

## Composants

- Composants natifs React Native : `View`, `Text`, `ScrollView`, `FlatList`.
- Pas de composants web (`div`, `span`).
- Touchables : `Pressable`, `TouchableOpacity`.

## Responsive

- Dimensions via `Dimensions.get('window')` ou `useWindowDimensions()`.
- Unités : `dp` (pas de `px`).
- SafeAreaView pour les notchs iOS.

## Polices

- Polices système par défaut.
- Polices custom via `expo-font`.
