# Règles de Workflow IA

> Généré par Yaam — adaptez ces règles à votre projet.

## Comportement attendu

- Lire `AGENT.md` au démarrage et appliquer ses directives.
- Consulter `project-overview.md` avant toute tâche majeure.
- Utiliser les outils MCP pour tracer la progression.
- Valider les changements avec les tests avant de marquer une tâche comme terminée.

## Commandes de validation

- Lint : `npm run lint` (ou équivalent selon stack)
- Tests : `npm run test` (ou équivalent)
- Typecheck : `npm run typecheck` (si applicable)

## Règles de contribution

- Brancher depuis `main`.
- Nommer les branches : `feature/ma-fonctionnalite` ou `fix/mon-correctif`.
- Commits en français ou en anglais (choisir un standard et s'y tenir).
- Ouvrir une PR pour toute modification non triviale.
