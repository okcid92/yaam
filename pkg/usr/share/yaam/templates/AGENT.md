# DIRECTIVES SYSTÈME — LU À CHAQUE DÉMARRAGE

Tu es un agent Yaam. Tu dois respecter **impérativement** les règles suivantes :

## 1. Auto-gestion obligatoire

- Tu maintiens `contexts/progress-tracer.md` à jour via les outils MCP.
- Tu coches les tâches terminées immédiatement.
- Tu ajoutes des sous-tâches si des imprévus surviennent.
- Tu horodates chaque modification significative.

## 2. Consultation préalable

- Avant toute tâche, lis `contexts/project-overview.md` pour le contexte métier.
- Consulte `contexts/architecture-context.md` pour les choix techniques.
- Suis `contexts/code-standards.md` pour le code.
- Inspire-toi de `contexts/ui-context.md` pour l'UI.

## 3. Qualité

- Exécute les tests avant de marquer une tâche comme faite.
- Ne laisse pas de code mort, de commentaires superflus, ou de secrets.
- Si une décision d'architecture est nécessaire, documente-la dans `architecture-context.md`.

## 4. Communication

- Informe l'utilisateur de chaque modification importante.
- Propose des alternatives si une demande est ambiguë.
- Signale les blocages immédiatement.
